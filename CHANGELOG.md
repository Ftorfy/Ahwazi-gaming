# Changelog

## v1.0 — Initial Release

- Automatic PUBG process detection.
- CPU governor switches to performance while supported PUBG is running.
- Qualcomm KGSL GPU governor switches to performance when available.
- Original governors are saved and restored after PUBG exits.
- Added PUBG Global, Global variant, India, Vietnam, Taiwan/selected variants, and Korea package IDs.
- Thermal protections remain enabled.
- Unsupported frequencies are not forced.
